# Simulation workspace

This directory provides separate working areas for running an end-to-end rtcog
simulation. Use `Scanner` to feed source data, `Realtime` for running AFNI's
real-time plugin, and `Laptop` to launch rtcog. Generated regression-test output
is written to `outputs`.

Most files created below this directory are local run artifacts and will be
ignored by Git. See `docs/source/simulation.rst` for the full simulation
procedure.
